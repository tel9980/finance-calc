# 财务计算器 · finance-calc

一个纯前端的财务计算器，托管在 Cloudflare Workers（Static Assets）。个人理财 + 公司财务两套：前者算存款贷款、税费、买房、家庭规划，后者算发票税额、增值税、折旧、保本点、报表指标、报销核销、应收账龄、资金排期与报价毛利。

线上地址：**https://js.1211.cc.cd**

## 功能

| 模块 | 算什么 |
| --- | --- |
| 存款利息 | 单利 / 按年复利 / 按月复利；利息、本息合计、实际年化、每月每天折合 |
| 贷款月供 | 等额本息、等额本金；月供、总利息、利息占本金比，逐期还款计划表 |
| 组合贷 | 商贷 + 公积金两笔并行，分别月供与合计利息；对比"全部按商贷"能省多少 |
| 提前还款 | 缩期限保月供 / 减月供保期限两种方案；省息、期数变化、扣违约金后净省 |
| 复利/定投 | 初始本金 + 每月定投 + 年化收益；期末总额、累计收益、翻倍年数 |
| 攒钱目标 | 按每月存入推算还要多久达成、预计达成月份；反推「X 年内攒够每月需存多少」 |
| 分期利率 | 信用卡/消费分期手续费换算真实年化（IRR 口径），名义年化倍数对比 |
| 年化换算 | 复利年化（CAGR）、单利年化、区间收益率、日均收益 |
| 通胀购买力 | 未来购买力折现、维持同等生活所需金额、购买力缩水幅度 |
| 个税测算 | 年度综合所得税额；年终奖「单独计税」与「并入综合所得」对比取优 |
| 折扣单价 | 折扣 + 满减叠加后的实际支付与真实折扣；两件商品按每克/毫升/个比单价 |
| 到手工资 | 累计预扣法算当月个税与到手；五险一金、公积金比例、专项附加扣除可调；含公司缴纳部分 |
| 租房还是买房 | 买房期末净资产 vs 租房（首付+月供差额去理财）对比，并用二分法算临界房价涨幅 |
| 信用卡利息 | 只还最低还款的滚动计息模拟：首期利息、还清期数、累计利息、折合年化 |
| 汇率单位换算 | 手动填汇率算换汇与扣点差后的到账；长度/重量/面积/体积/温度互换 |
| 公积金额度 | 余额倍数法、按还款能力反推、当地限额三种口径取最小值，估可贷额度、月供与自筹缺口 |
| 利率调整月供 | 存量房贷 LPR 重定价：期限不变时新月供、每月差额与剩余总利息变化 |
| 二手房税费 | 契税、增值税及附加、个税、中介费估算，给出买方需准备的总房款与税费占比 |
| AA 分摊 | 含服务费/小费的人均分摊，支持抹零到元/10 元，零头归发起人 |
| 退休金测算 | 职工养老保险退休金估算：基础养老金 + 个人账户养老金（按退休年龄取计发月数），给替代率与缺口所需自备资金 |
| 卖房换房 | 卖房到手净额（房价−剩余贷款−卖方税费），与新房首付对比算资金缺口、新贷月供 |
| 公积金对冲 | 月冲（逐月抵月供，不减本金）vs 年冲（每年一次性冲本金，减月供或缩期限）的利息与现金流对比 |
| 多币种折算 | 一笔钱按手填汇率折成美元/欧元/日元/港币/英镑，并折算银行点差损耗 |
| 年终奖拆分 | 单独计税 vs 并入综合所得 vs 最优拆分（1 元级搜索），含跳档「陷阱区间」提醒 |
| 专项附加扣除 | 子女教育/婴幼儿/继续教育/房贷利息/租金/赡养老人/大病医疗逐项填，算全年少缴多少 |
| 存单阶梯 | 三等分存 1/2/3 年期的到期排布，与全存 3 年期的利息代价对比 |
| 租售比 | 房东视角：租售比、有效与净回报、月供现金流、持有到期 IRR（含杠杆与涨价） |
| 提前还款 vs 理财 | 同一笔闲钱「还贷降月供 + 差额定投」对比「买理财照旧还贷」，按 N 年后净资产裁定谁更划算 |
| 教育金 | 按学费涨幅推算上大学时 4 年总花费、已有存款的复利终值、缺口与每月需存 |
| 保险保额 | 家庭责任法 + 收入倍数法夹出寿险保额，并给重疾/意外建议与保费预算区间 |
| 买车 vs 打车 | 折旧+油费+保险保养停车的每公里真实成本，与同里程打车花费对比 |
| 年度汇算退税 | 全年收入合并重算，对比已预扣税额，算该退税还是补税；含劳务报酬 80% 计入 |
| 家庭资产负债 | 六项资产四类负债一页盘点：净资产、负债率、房产集中度、应急金月数、月供收入比 |
| 灵活就业社保 | 自己缴社保每月多少钱、个人账户攒多少、退休能领多少、总缴费几年回本 |
| 社保少缴核查 | 按真实工资 vs 申报基数算少缴金额（个人/单位/个人账户），附维权路径 |
| 三种还法对撞 | 同一笔提前还款，缩短期限 vs 减少月供的省息差额、每 10 万元省息、月供占收入 |
| 定投 vs 一次性 | 相同金额分批投 vs 一把梭的期望值、2000 次蒙卡胜率、中位数与最差 5% 情形 |
| 保单体检 | 现有保额 vs 应配保额（寿险责任法/收入倍数法、重疾 3–5 倍、意外 10 倍），出缺口 |
| 到期日历 | 多笔存款/理财错开起存，列出每笔到期日与本息，避免同时到期 |
| 现金流月历 | 把发薪日、房贷扣款日、信用卡还款日排进一个月，逐日算余额，找出月光中最紧的那天与所需缓冲金 |
| 0 利率真实成本 | 「免息」车贷/装修贷/分期的手续费折成 IRR 真实年化，叠加放弃的全款优惠，判断贷款还是全款划算 |
| 风险测评配置 | 按年龄、期限、回撤容忍度、收入稳定性给股/债/现金比例与金额，并算出极端年份可能亏多少 |
| 违约金临界点 | 提前还款的等效年化（现金流 IRR）与违约金临界费率，直接对比你的理财收益 |
| 债务先还哪笔 | 最多三笔债务，雪崩法（先还利率最高）vs 雪球法（先还余额最小）的还清月数、总利息差，以及"只还最低"要还多久 |
| FIRE 自由 | 按年支出 ÷ 安全提取率算所需本金，反推达成年龄、当前进度、10 年内达成需每月存多少，以及收益敏感性 |
| 年缴费用分摊 | 物业费、车险、寿险、学费等年缴费用摊到每月，找出缴费最集中的月份与要提前几个月开始存 |
| 买房预算反推 | 由月收入、现金、首付比例反推能承受的房价总价，说明卡在"月供"还是"现金"，并算出月供占比与总利息 |
| 商转公 | 剩余商贷转公积金（或转一部分成组合贷）后的月供、省息、一次性成本回本月数，以及额度不够时的混合方案 |
| 医保报销 | 总费用扣掉目录外自费、起付线后按比例报销，叠加大病保险，算出你实际自付与实际报销比例 |
| 养娃成本 | 从孩子当前年龄到 22 岁毕业的分段花费，含通胀的名义总额、折现现值、最贵那年、现在每月要存多少 |
| 个人养老金账户 | 每年 12000 元的省税、账户终值、领取时 3% 缴税，对比同样钱自己投，按不同边际税率给出净收益差 |
| 公积金缴存额度 | 反推「要贷到目标额度，账户余额还差多少、月缴 2000/3000/5000/8000 各要等几个月」，并算月供 |
| 应急金 | 按收入稳定性、房贷、养娃算出该备几个月刚性支出，给出缺口与补足月数 |
| 收入分配体检 | 50/30/20 结构对照：必需、可选、储蓄三档占比与基准差多少，要砍支出还是要涨收入 |
| 债务置换 | 同月供下，把高息债换成低息新贷能省多少，并算出手续费率高到多少就不划算 |
| 信用卡免息期 | 按账单日/还款日算这笔消费的免息天数、最长免息期与最优刷卡日，并把「没还清就全额计息」的代价摆出来 |
| 加班费与请假 | 用 21.75 天折时薪，算 1.5/2/3 倍加班费与事假病假扣款，给出当月应发合计 |
| 涨租 vs 搬家 | 把涨租的多付与搬家的固定成本摊到同一条时间轴上，算临界居住月数 |
| 油车 vs 电车 | 能源＋保养＋保险＋折旧残值全算进去，给出盈亏平衡的年里程 |
| 发票价税分离 | 含税/不含税互转：金额、税额、附加税费，并按 13/9/6/5/3/1% 列出同一笔金额在各税率下的拆分 |
| 增值税与附加 | 销项 − 进项 − 留抵 = 应交增值税，期末留抵结转；城建/教育/地方教育附加，税负率，以及「税负率 ≈ 税率 × 毛利率」对照 |
| 固定资产折旧 | 年限平均 / 双倍余额递减 / 年数总和三种方法，月折旧、累计折旧、账面净值、年度折旧表，附税法最低折旧年限 |
| 保本点与目标利润 | 单位边际贡献、边际贡献率、保本销量与销售额、目标利润销量、安全边际率、经营杠杆 |
| 报表体检（杜邦） | 毛利率、净利率、流动/速动比率、资产负债率、ROA/ROE、应收与存货周转天数，ROE 按净利率×周转率×权益乘数拆开 |
| 银行余额调节 | 四类未达账项两侧调节，调节后余额是否相等、差额多少，不平就提示逐笔查 |
| 差旅报销单 | 住宿/餐补/交通按制度标准核，超标部分自付；算出可抵扣进项税与企业实际费用成本 |
| 应收账龄 | 四档账龄余额按比例计提坏账准备，综合计提率、本期应补提（或冲回）、计提后净额 |
| 资金排期 | 按回款日与各笔付款日排出当月余额曲线，找出最低点、缺口金额和资金转负的那天 |
| 报价毛利 | 按目标毛利率反推含税报价，算折扣对各档毛利率的影响，也校验客户给价能剩多少毛利 |
| 三表勾稽 | 用利润表的净利润按间接法推经营现金流，验证「间接法 vs 表上」「期初＋三项＝期末」「资产＝负债＋权益」三处是否相等，差额多少、先查哪里 |
| 多产品组合毛利 | 4 个产品的收入、毛利、毛利率与收入占比，算出加权综合毛利率，挑出低于综合线和负毛利的产品，并给出剔掉负毛利后的毛利率 |
| 应付账款现金折扣 | 2/10 net 30 这类条件：折扣收益、早付要自筹多少、借钱利息、净赚多少，算出「放弃折扣的年化成本」这条临界线 |
| 固定资产台账 | 3 张卡片按直线法算月折旧、累计折旧、净值、剩余月数，合计本月折旧、未来 12 个月还要提多少，标出已提足与快提足的卡片 |
| 应付账龄 | 四档账龄余额、加权平均账龄、超信用期金额与占比、应付周转天数、无偿占用供应商资金的价值，以及账期再加 30 天能多省多少 |
| 成本核算（品种法） | 材料按 100%、人工与制费按完工程度折算约当产量，算出单位成本、完工产品成本、月末在产品成本，验证两项之和等于投入合计 |
| 预算差异分析 | 预算→弹性预算→实际三层比较，拆成销量差异、售价差异、材料价差、材料量差，并指出最大拖累项该找哪个部门 |
| 月度利润表 | 从收入到净利润的粗表（毛利、营业利润、利润总额、所得税、净利），每项占收入比、三费占比、保本营业收入 |
| 开票与收款台账 | 一个合同的含税金额拆成不含税与税额，算开票进度、回款进度、应收余额、逾期占比与可主张罚息 |
| 费用预算差异 | 五个科目逐行比预算与实际，给出超支与节约合计、超支最多的科目、要压回预算需砍多少 |
| 人效与费用率 | 人均创收/毛利/净利、人工成本率、期间费用率、每 1 元人工创造的收入、保本人均创收与安全倍数 |
| 现金流量表 | 经营、投资、筹资三段净额与现金净增加，自由现金流、流入流出比，并判断处在扩张还是失血状态 |
| 存货周转与库龄 | 周转率/周转天数、平均存货、库龄四档结构与呆滞占比、建议跌价准备、缩短 10 天可释放多少现金 |
| 出口退税免抵退 | 免抵退税额、不得免征和抵扣（进项转出）、内销销项抵减、应退税额与免抵额、结转下期留抵 |
| 往来对账差额 | 我方与对方余额双向调节，四类未达/漏记分类、调节后双方数额与结论，剩多少差额没解释 |
| 三费趋势（6 期） | 逐期费用率与环比、加权平均费用率、费用与收入增速对比、按同步增长「应花」与实际多花 |
| 多产品保本 | 按销售结构分摊固定成本，算加权边际贡献率、整体与各产品保本额/保本量，指出哪个产品在补贴哪个 |
| 工资表代扣勾稽 | 应发 − 社保 − 公积金 − 个税 − 其他 = 实发；表内个税与申报数比对；算出用工总成本与人工成本率 |
| 固定资产盘点差异 | 盘亏净值＋进项转出 − 赔偿保险 = 净损失；盘盈按重置价×成新率入账；给出对损益与所得税的影响 |
| 月度关账进度 | 完成率、剩余人日、并行需要几天、能不能赶上截止日，按剩余天数给出需要投入的人数 |
| 应收保理 | 利息＋手续费＋保证金占用折成全口径年化，跟流贷比谁便宜，附各期限年化曲线 |
| 呆滞库存清理 | 等待 / 清仓 / 报废三种处置的每件净回收、临界价与总回收金额 |
| 账期谈判 | 延长账期多占用的资金收益 vs 供应商加价，算可接受的临界加价率 |

| 贷款真实利率 | 服务费、保证金、按月还本一起折 IRR，真实年化比名义高几个点 |

| 月度经营数据包 | 达成率、同比、毛利率净利率、DSO/DIO/现金周期、利润与现金流背离提示 |

## 口径与免责

- 结果均为数学测算，未计手续费、税费、通胀等额外因素（通胀有单独模块）。
- 个税按现行综合所得与全年一次性奖金政策估算（全年汇算口径），实际以扣缴义务人申报与税务机关口径为准。
- 分期年化与提前还款等效收益均按 IRR（内部收益率）折算，相当于监管要求披露的年化综合成本；具体以银行/平台披露为准。
- 资产配置比例与预期收益率为长期中枢假设（股 6%/债 3%/现金 1.5%），不构成投资建议；提前还款、贷款定价以合同与实际政策为准。
- 组合贷、提前还款的额度、利率、违约金规则以银行与公积金中心审批为准。
- 存款保险最高偿付 50 万元（本息合计，同一家银行）；理财不等于存款。
- 本项目不构成投资、信贷或税务建议。

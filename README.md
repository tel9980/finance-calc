# 财务计算器 · finance-calc

一个纯前端的财务计算器，托管在 Cloudflare Workers（Static Assets）。个人理财 + 公司财务两套：前者算存款贷款、税费、买房、家庭规划，后者算发票税额、增值税、折旧、保本点、报表指标、报销核销、应收账龄、资金排期与报价毛利。

线上地址：**https://js.1211.cc.cd**

## 功能

| 模块 | 算什么 |
| --- | --- |
| 存款利息 | 单利 / 按年复利 / 按月复利；利息、本息合计、实际年化、每月每天折合 |
| 贷款月供 | 等额本息、等额本金；月供、总利息、利息占本金比，逐期还款计划表 |
| 组合贷 | 商贷 + 公积金两笔并行，分别月供与合计利息；对比"全部按商贷"能省多少 |
| 提前还款 | 缩期限保月供 / 减月供保期限两种方案；省息、期数变化、扣违约金后净省 |
| 复利/定投 | 初始本金 + 每月定投 + 年化收益；期末总额、累计收益、翻倍年数 |
| 攒钱目标 | 按每月存入推算还要多久达成、预计达成月份；反推「X 年内攒够每月需存多少」 |
| 分期利率 | 信用卡/消费分期手续费换算真实年化（IRR 口径），名义年化倍数对比 |
| 年化换算 | 复利年化（CAGR）、单利年化、区间收益率、日均收益 |
| 通胀购买力 | 未来购买力折现、维持同等生活所需金额、购买力缩水幅度 |
| 个税测算 | 年度综合所得税额；年终奖「单独计税」与「并入综合所得」对比取优 |
| 折扣单价 | 折扣 + 满减叠加后的实际支付与真实折扣；两件商品按每克/毫升/个比单价 |
| 到手工资 | 累计预扣法算当月个税与到手；五险一金、公积金比例、专项附加扣除可调；含公司缴纳部分 |
| 租房还是买房 | 买房期末净资产 vs 租房（首付+月供差额去理财）对比，并用二分法算临界房价涨幅 |
| 信用卡利息 | 只还最低还款的滚动计息模拟：首期利息、还清期数、累计利息、折合年化 |
| 汇率单位换算 | 手动填汇率算换汇与扣点差后的到账；长度/重量/面积/体积/温度互换 |
| 公积金额度 | 余额倍数法、按还款能力反推、当地限额三种口径取最小值，估可贷额度、月供与自筹缺口 |
| 利率调整月供 | 存量房贷 LPR 重定价：期限不变时新月供、每月差额与剩余总利息变化 |
| 二手房税费 | 契税、增值税及附加、个税、中介费估算，给出买方需准备的总房款与税费占比 |
| AA 分摊 | 含服务费/小费的人均分摊，支持抹零到元/10 元，零头归发起人 |
| 退休金测算 | 职工养老保险退休金估算：基础养老金 + 个人账户养老金（按退休年龄取计发月数），给替代率与缺口所需自备资金 |
| 卖房换房 | 卖房到手净额（房价−剩余贷款−卖方税费），与新房首付对比算资金缺口、新贷月供 |
| 公积金对冲 | 月冲（逐月抵月供，不减本金）vs 年冲（每年一次性冲本金，减月供或缩期限）的利息与现金流对比 |
| 多币种折算 | 一笔钱按手填汇率折成美元/欧元/日元/港币/英镑，并折算银行点差损耗 |
| 年终奖拆分 | 单独计税 vs 并入综合所得 vs 最优拆分（1 元级搜索），含跳档「陷阱区间」提醒 |
| 专项附加扣除 | 子女教育/婴幼儿/继续教育/房贷利息/租金/赡养老人/大病医疗逐项填，算全年少缴多少 |
| 存单阶梯 | 三等分存 1/2/3 年期的到期排布，与全存 3 年期的利息代价对比 |
| 租售比 | 房东视角：租售比、有效与净回报、月供现金流、持有到期 IRR（含杠杆与涨价） |
| 提前还款 vs 理财 | 同一笔闲钱「还贷降月供 + 差额定投」对比「买理财照旧还贷」，按 N 年后净资产裁定谁更划算 |
| 教育金 | 按学费涨幅推算上大学时 4 年总花费、已有存款的复利终值、缺口与每月需存 |
| 保险保额 | 家庭责任法 + 收入倍数法夹出寿险保额，并给重疾/意外建议与保费预算区间 |
| 买车 vs 打车 | 折旧+油费+保险保养停车的每公里真实成本，与同里程打车花费对比 |
| 年度汇算退税 | 全年收入合并重算，对比已预扣税额，算该退税还是补税；含劳务报酬 80% 计入 |
| 家庭资产负债 | 六项资产四类负债一页盘点：净资产、负债率、房产集中度、应急金月数、月供收入比 |
| 灵活就业社保 | 自己缴社保每月多少钱、个人账户攒多少、退休能领多少、总缴费几年回本 |
| 社保少缴核查 | 按真实工资 vs 申报基数算少缴金额（个人/单位/个人账户），附维权路径 |
| 三种还法对撞 | 同一笔提前还款，缩短期限 vs 减少月供的省息差额、每 10 万元省息、月供占收入 |
| 定投 vs 一次性 | 相同金额分批投 vs 一把梭的期望值、2000 次蒙卡胜率、中位数与最差 5% 情形 |
| 保单体检 | 现有保额 vs 应配保额（寿险责任法/收入倍数法、重疾 3–5 倍、意外 10 倍），出缺口 |
| 到期日历 | 多笔存款/理财错开起存，列出每笔到期日与本息，避免同时到期 |
| 现金流月历 | 把发薪日、房贷扣款日、信用卡还款日排进一个月，逐日算余额，找出月光中最紧的那天与所需缓冲金 |
| 0 利率真实成本 | 「免息」车贷/装修贷/分期的手续费折成 IRR 真实年化，叠加放弃的全款优惠，判断贷款还是全款划算 |
| 风险测评配置 | 按年龄、期限、回撤容忍度、收入稳定性给股/债/现金比例与金额，并算出极端年份可能亏多少 |
| 违约金临界点 | 提前还款的等效年化（现金流 IRR）与违约金临界费率，直接对比你的理财收益 |
| 债务先还哪笔 | 最多三笔债务，雪崩法（先还利率最高）vs 雪球法（先还余额最小）的还清月数、总利息差，以及"只还最低"要还多久 |
| FIRE 自由 | 按年支出 ÷ 安全提取率算所需本金，反推达成年龄、当前进度、10 年内达成需每月存多少，以及收益敏感性 |
| 年缴费用分摊 | 物业费、车险、寿险、学费等年缴费用摊到每月，找出缴费最集中的月份与要提前几个月开始存 |
| 买房预算反推 | 由月收入、现金、首付比例反推能承受的房价总价，说明卡在"月供"还是"现金"，并算出月供占比与总利息 |
| 商转公 | 剩余商贷转公积金（或转一部分成组合贷）后的月供、省息、一次性成本回本月数，以及额度不够时的混合方案 |
| 医保报销 | 总费用扣掉目录外自费、起付线后按比例报销，叠加大病保险，算出你实际自付与实际报销比例 |
| 养娃成本 | 从孩子当前年龄到 22 岁毕业的分段花费，含通胀的名义总额、折现现值、最贵那年、现在每月要存多少 |
| 个人养老金账户 | 每年 12000 元的省税、账户终值、领取时 3% 缴税，对比同样钱自己投，按不同边际税率给出净收益差 |
| 公积金缴存额度 | 反推「要贷到目标额度，账户余额还差多少、月缴 2000/3000/5000/8000 各要等几个月」，并算月供 |
| 应急金 | 按收入稳定性、房贷、养娃算出该备几个月刚性支出，给出缺口与补足月数 |
| 收入分配体检 | 50/30/20 结构对照：必需、可选、储蓄三档占比与基准差多少，要砍支出还是要涨收入 |
| 债务置换 | 同月供下，把高息债换成低息新贷能省多少，并算出手续费率高到多少就不划算 |
| 信用卡免息期 | 按账单日/还款日算这笔消费的免息天数、最长免息期与最优刷卡日，并把「没还清就全额计息」的代价摆出来 |
| 加班费与请假 | 用 21.75 天折时薪，算 1.5/2/3 倍加班费与事假病假扣款，给出当月应发合计 |
| 涨租 vs 搬家 | 把涨租的多付与搬家的固定成本摊到同一条时间轴上，算临界居住月数 |
| 油车 vs 电车 | 能源＋保养＋保险＋折旧残值全算进去，给出盈亏平衡的年里程 |
| 发票价税分离 | 含税/不含税互转：金额、税额、附加税费，并按 13/9/6/5/3/1% 列出同一笔金额在各税率下的拆分 |
| 增值税与附加 | 销项 − 进项 − 留抵 = 应交增值税，期末留抵结转；城建/教育/地方教育附加，税负率，以及「税负率 ≈ 税率 × 毛利率」对照 |
| 固定资产折旧 | 年限平均 / 双倍余额递减 / 年数总和三种方法，月折旧、累计折旧、账面净值、年度折旧表，附税法最低折旧年限 |
| 保本点与目标利润 | 单位边际贡献、边际贡献率、保本销量与销售额、目标利润销量、安全边际率、经营杠杆 |
| 报表体检（杜邦） | 毛利率、净利率、流动/速动比率、资产负债率、ROA/ROE、应收与存货周转天数，ROE 按净利率×周转率×权益乘数拆开 |
| 银行余额调节 | 四类未达账项两侧调节，调节后余额是否相等、差额多少，不平就提示逐笔查 |
| 差旅报销单 | 住宿/餐补/交通按制度标准核，超标部分自付；算出可抵扣进项税与企业实际费用成本 |
| 应收账龄 | 四档账龄余额按比例计提坏账准备，综合计提率、本期应补提（或冲回）、计提后净额 |
| 资金排期 | 按回款日与各笔付款日排出当月余额曲线，找出最低点、缺口金额和资金转负的那天 |
| 报价毛利 | 按目标毛利率反推含税报价，算折扣对各档毛利率的影响，也校验客户给价能剩多少毛利 |
| 三表勾稽 | 用利润表的净利润按间接法推经营现金流，验证「间接法 vs 表上」「期初＋三项＝期末」「资产＝负债＋权益」三处是否相等，差额多少、先查哪里 |
| 多产品组合毛利 | 4 个产品的收入、毛利、毛利率与收入占比，算出加权综合毛利率，挑出低于综合线和负毛利的产品，并给出剔掉负毛利后的毛利率 |
| 应付账款现金折扣 | 2/10 net 30 这类条件：折扣收益、早付要自筹多少、借钱利息、净赚多少，算出「放弃折扣的年化成本」这条临界线 |
| 固定资产台账 | 3 张卡片按直线法算月折旧、累计折旧、净值、剩余月数，合计本月折旧、未来 12 个月还要提多少，标出已提足与快提足的卡片 |
| 应付账龄 | 四档账龄余额、加权平均账龄、超信用期金额与占比、应付周转天数、无偿占用供应商资金的价值，以及账期再加 30 天能多省多少 |
| 成本核算（品种法） | 材料按 100%、人工与制费按完工程度折算约当产量，算出单位成本、完工产品成本、月末在产品成本，验证两项之和等于投入合计 |
| 预算差异分析 | 预算→弹性预算→实际三层比较，拆成销量差异、售价差异、材料价差、材料量差，并指出最大拖累项该找哪个部门 |
| 月度利润表 | 从收入到净利润的粗表（毛利、营业利润、利润总额、所得税、净利），每项占收入比、三费占比、保本营业收入 |
| 开票与收款台账 | 一个合同的含税金额拆成不含税与税额，算开票进度、回款进度、应收余额、逾期占比与可主张罚息 |
| 费用预算差异 | 五个科目逐行比预算与实际，给出超支与节约合计、超支最多的科目、要压回预算需砍多少 |
| 人效与费用率 | 人均创收/毛利/净利、人工成本率、期间费用率、每 1 元人工创造的收入、保本人均创收与安全倍数 |
| 现金流量表 | 经营、投资、筹资三段净额与现金净增加，自由现金流、流入流出比，并判断处在扩张还是失血状态 |
| 存货周转与库龄 | 周转率/周转天数、平均存货、库龄四档结构与呆滞占比、建议跌价准备、缩短 10 天可释放多少现金 |
| 出口退税免抵退 | 免抵退税额、不得免征和抵扣（进项转出）、内销销项抵减、应退税额与免抵额、结转下期留抵 |
| 往来对账差额 | 我方与对方余额双向调节，四类未达/漏记分类、调节后双方数额与结论，剩多少差额没解释 |
| 三费趋势（6 期） | 逐期费用率与环比、加权平均费用率、费用与收入增速对比、按同步增长「应花」与实际多花 |
| 多产品保本 | 按销售结构分摊固定成本，算加权边际贡献率、整体与各产品保本额/保本量，指出哪个产品在补贴哪个 |
| 工资表代扣勾稽 | 应发 − 社保 − 公积金 − 个税 − 其他 = 实发；表内个税与申报数比对；算出用工总成本与人工成本率 |
| 固定资产盘点差异 | 盘亏净值＋进项转出 − 赔偿保险 = 净损失；盘盈按重置价×成新率入账；给出对损益与所得税的影响 |
| 月度关账进度 | 完成率、剩余人日、并行需要几天、能不能赶上截止日，按剩余天数给出需要投入的人数 |
| 应收保理 | 利息＋手续费＋保证金占用折成全口径年化，跟流贷比谁便宜，附各期限年化曲线 |
| 呆滞库存清理 | 等待 / 清仓 / 报废三种处置的每件净回收、临界价与总回收金额 |

## 特点

- 顶部搜索框：输入模块名（如「折旧」「大写」「工作日」）直接过滤，跨分类查找。

## 工程上的几件事

- **离线可用（PWA）**：`manifest.webmanifest` + `sw.js`，手机浏览器「添加到主屏幕」后可离线打开；SW 采用「导航网络优先回落缓存、静态资源缓存优先」的策略，改版后旧缓存自动清理（版本号由文件内容哈希生成）。
- **静态资源内容指纹 + 长缓存**：`public/assets/app.<hash>.js`、`public/assets/style.<hash>.css`，`_headers` 里给 1 年 `immutable`；`index.html` 本身仍是 `max-age=0, must-revalidate`，所以改版立即生效。**改完 `public/app.js` 或 `style.css` 必须先 `node scripts/fingerprint.mjs` 再部署**，否则线上还是旧哈希文件。
- **对比 A/B**：同一模块改参数前后各点一次「对比 A/B」，弹出对照表（A / B / 差异，变化的行标蓝），参数改动也列在下面；A 快照存在本机，关掉浏览器也在。
- **家庭财务体检**：把储蓄率、应急金、负债率、月供比、保障覆盖五件事一起打分（各 20 分），直接指出最短那块板；可一键读取「收入分配体检」「应急金」「现金流月历」里已填的数。
- **分享卡片与收录**：`og:` / `twitter:` 卡片、`og.png`（1200×630）、`sitemap.xml`、`application/ld+json`（WebApplication）。
- **打印/存 PDF**：点「打印」只输出当前模块，并自动加一页封面（模块名 + 时间），表格不再内部滚动、表头跨页重复。
- **手机端**：结果区的核心数字吸顶跟随滚动，看明细表时不用来回翻。
- **结果图 / 竖版长图**：点「结果图」导出横版卡片，「竖版长图」导出窄高版（更适合发群里 / 朋友圈），图里都带「当前参数」的分享链接。
- **输入框内嵌单位**：百分比、年/月/天、岁、公里等输入框右端直接显示单位（只显示，不参与保存），金额框保持干净。
- **组合规划（买房后体检）**：把「收入/现金/目标房价/利率年限/月支出/保额」放一屏，直接算出买房后的储蓄率、应急金、负债率、月供比与保障覆盖，给出「现在 85 分 → 买房后 45 分」这种前后对比，并反推「现金能撑的房价上限」。
- **数字输入更好用**：所有金额框支持 `1.5万`、`2k`、`3千`、`1亿` 这种简写，失焦自动加千分位，↑/↓ 按每格 `step` 步进（按住 Shift 走 10 格）；只接受数字，粘贴带逗号的金额也能直接算。
- **模块之间带参跳转**：每个结论底下有一排「接着算」，点一下就把当前金额带到下一个模块（贷款 → 提前还款 / 三种还法 / 组合贷 / 违约金临界点；租还是买 ↔ 房东视角租售比 ↔ 签字要备多少现金；体检 → 应急金 / FIRE / 保额 / 年度报告；12 个月小结 → 支出结构，全年分类自动折成月均）。
- **无障碍**：`Tab` 第一下落在「跳到计算区」，`:focus-visible` 有清晰焦点框，结果区 `aria-live="polite"`（读屏会念新结果），尊重「减少动态效果」系统设置，深色模式下次要文字对比度按 AA 调过。
- **出错不白屏**：任何脚本异常都会在底部弹一张诊断卡（含时间、页面、面板、浏览器、视口、错误摘要），一键「复制诊断信息」，方便报问题。
- **chunk 预取**：鼠标移到（或键盘聚焦到）某个模块标签时，提前 120 ms 把那块代码拉下来；手指/鼠标按下（pointerdown）也立即预取；空闲时预热「存款」「贷款」以及你**最近用过的 3 个模块**，点开几乎是瞬开。
- **本地存储写满会提示**：隐私模式或存满导致写不进 `localStorage` 时不再静默失败，会提示去「方案快照」导出备份。
- **备份与迁移**：在「方案快照」页可以把快照导出成 JSON（换设备、发给同事都行），也能「整站备份」——把填写过的参数、置顶、预设、快照、主题打包成一个文件，换手机时「恢复备份」一键还原（全部在本机完成，不上传）。
- **月度跟踪**：在「方案快照」页可以按月给同一个模块存两版（如「10 月」「11 月」），点「生成跟踪表」并排看「上一版 vs 最新一版」的变化，有变化的行为蓝色。
- **按分类懒加载**：`src/app.js` 拆成「核心 87 KB + 9 个分类 chunk」，**面板 HTML 也一起按分类拆**（`index.html` 只留框架和当前分类的面板），首屏只下核心 + 当前分类；点开「公司财务」才去拿那块 557 KB；所有资源文件名带内容哈希，SW 顺手缓存，第二次点开是零请求。
- **构建方式**：源码在 `src/app.js`（全部模块函数）与 `src/panels.html`（全部面板 HTML，按 tab 顺序），改完跑 `node scripts/build.mjs`——它会自动切分 chunk、算哈希、改写 `index.html` 引用并重建 `sw.js`，全程无第三方依赖；`public/` 下的 `assets/*` 是生成物，不要直接改。

- **顶部搜索**：输入模块名或拼音首字母（如 `vat`、`账期`）即时过滤；支持「分类 关键词」前缀（如 `税 年终奖`、`公司 折旧`、`tax:年终奖`）只在某个分类里找；按 `/` 聚焦搜索框，`Esc` 清空。

- **分享链接**：点「复制分享链接」把「当前模块 + 当前填的所有参数」编码进 URL，发给同事打开即是他看到的那一版结果。

- **参数预设**：把一套参数存成预设（如「A 客户报价」「30 年商贷」），下次从下拉里选回来即用；只存在本机浏览器。
- **深色模式**：右上「深色/浅色」切换，首次打开跟随系统设置，选择会记住。
- **命令面板**：按 `Ctrl/Cmd + K`（或点工具栏「⌘K 搜模块」）弹出面板，输中文名 / 英文 id / 拼音即时过滤 228 个模块，`↑↓` 选、`Enter` 打开、`Esc` 关。
- **下一步常用**：每个高频模块算完后，结果卡底部会给出顺手的后续入口（如 存款 → 复利定投 / 存单阶梯；贷款 → 提前还款 / 组合贷），点一下带参数跳过去；推荐顺序会跟着你最近用过的模块动态排。
- **搜索支持视图前缀**：输入 `最近:` / `置顶:`（或 `最近 关键词`）直接只在「最近用过的」或「已置顶」里找。
- **切页 O(1)**：切换模块只摘掉上一个、点亮当前，不再每次扫 228 个节点，低端手机切页更跟手。
- **输入纠错**：数字框里如果敲出 `1..2` 这类不是数字的内容，输入框会标红提醒，改对即恢复。
- **点击即复制**：结果卡里任意一个数字（月供、总额、比率…）点一下就直接复制到剪贴板，右下角会提示「已复制：xxx」。
- **长列表工具栏**：有明细表的模块（如贷款还款计划、存单阶梯）表上方自动出现「复制表格 / 打印」——复制表格是 TSV 格式，粘进 Excel 直接分列。
- **假设说明可折叠**：每个模块结果卡底部的「假设说明」默认展开，点一下标题即可收起，打印/截图时不显示小箭头。
- **搜索带分类徽标**：搜索时每个命中的标签右侧显示它属于哪个分类（如「工资税费」「公司财务」），跨分类找东西一眼看清。

## 装到手机主屏（当 App 用）

不用装商店、不用输账号，浏览器里添加一次，桌面上就多一个图标，点开是全屏独立窗口，断网也能算：

- **安卓 / Chrome、Edge**：打开站点后，底部会弹一条「装到主屏，断网也能算」的提示，点「安装」即可；也可以点工具栏里的「安装到主屏」，或浏览器菜单里的「安装应用」。装好后长按图标还能看到快捷方式（财务工作流 / 贷款月供 / 到手工资 / 家庭财务体检）。
- **iPhone / iPad**：Safari 没有一键安装，点底部「分享」→「添加到主屏幕」。第一次进来会弹一条图文指引（点 × 关掉后 30 天内不再打扰），工具栏里也有「怎么装到主屏」。
- **装好之后**：`manifest.webmanifest` 里声明了 `display: standalone`，所以是独立窗口（没有地址栏）；`theme_color`、图标、启动背景色都按 App 的样子配好了；已经装好时不会再提示安装。
- **离线的边界**：外壳（页面 + 主程序 + 样式）第一次打开就缓存好了；装到主屏后会在后台把 16 个分组依次预取下来（省流量模式或断网时不做），之后 228 个模块全部离线可算。普通浏览器里没装、也没点过的分组，第一次仍需联网。
- **更新**：改版后部署即生效，老页面会弹一条「有新版本了 → 刷新」，点一下就是新版；首次安装不会再误报「有新版本」。

相关文件：`public/manifest.webmanifest`、`public/icon-180.png`（iOS）、`public/icon-maskable-512.png`（安卓裁切安全区）、`public/shot-narrow.png` 与 `public/shot-wide.png`（安装弹窗里的预览图）、`public/sw.js`（由 `scripts/build.mjs` 生成）、`src/app.js` 里 `doInstall` / `syncInstallUi` / `prefetchAllChunks`。

## 口径与免责

- 结果均为数学测算，未计手续费、税费、通胀等额外因素（通胀有单独模块）。
- 个税按现行综合所得与全年一次性奖金政策估算（全年汇算口径），实际以扣缴义务人申报与税务机关口径为准。
- 分期年化与提前还款等效收益均按 IRR（内部收益率）折算，相当于监管要求披露的年化综合成本；具体以银行/平台披露为准。
- 资产配置比例与预期收益率为长期中枢假设（股 6%/债 3%/现金 1.5%），不构成投资建议；提前还款、贷款定价以合同与实际政策为准。
- 组合贷、提前还款的额度、利率、违约金规则以银行与公积金中心审批为准。
- 存款保险最高偿付 50 万元（本息合计，同一家银行）；理财不等于存款。
- 本项目不构成投资、信贷或税务建议。

node test/serve.mjs 8099 &  # 起本地静态服务器（无依赖）
node test/regress.mjs http://127.0.0.1:8099/    # 228 个模块数值对拍 test/baseline.json
node test/features.mjs  http://127.0.0.1:8099/  # 搜索 / 最近 / 快照备注 / 深链参数 / 工作流交互
node test/units.mjs     http://127.0.0.1:8099/  # 计算单测：拿教科书公式对答案

- `regress.mjs` 会把 228 个模块的主结果与 `test/baseline.json` 逐项对比（`dca` 蒙特卡洛随机不在对拍范围），并检查重复 id、控制台报错、手机端横向溢出。
- 改了计算逻辑且确认新结果正确时，用 `node test/regress.mjs http://127.0.0.1:8099/ --update` 重写基线，并把 baseline 的改动一起提交。
- `features.mjs` 除搜索 / 最近 / 快照备注 / 深链参数外，还覆盖财务工作流：三态勾选、备注弹层（含预计时长与截止日期）、逐步走完的浮动步骤条、月度归档、自定义路径的增删排序与导入、依赖缺失提示、首页今日待办、本月明细、打印交接单；`pwa.mjs` 另外覆盖到期提醒权限与通知发出。
- `units.mjs` 是「对公式」而不是「对昨天」：月供用 PMT 公式、等额本金总利息用等差数列求和、复利终值按期初/期末年金算、发票税额与应纳增值税按税率拆，期望值在测试里用**另一条路径**独立算出来再和页面比——这样能抓出「一直就错、但基线也跟着错」的问题；还会检查本金填 0、利率填负数时不会冒出 `NaN`。
- `pwa.mjs` 专测「装到主屏」这条链：manifest 字段是否齐（`id`/`display`/maskable 图标/narrow 截图）、引用的图标与截图能否取到、快捷方式指向的模块是否存在、iOS 上有没有出现「添加到主屏幕」指引、点 × 关掉后 30 天内不再弹、已经是独立窗口时不再提示安装，以及**装好后断网打开一个从没访问过的模块仍能算**。
- CI 配置在 `.github/workflows/ci.yml`（ubuntu + node 20 + chromium），六道闸：数值回归、交互回归、计算单测、安装/离线回归、构建产物同步、模块数口径。其中「构建产物同步」会在 CI 里重跑一遍 `npm run build` 再比对 `public/`——**只改 `src/` 忘了构建的提交会被拦下**，也不要手改 `public/` 里的产物。

## 分享与导出
- **结果图**（工具栏「结果图」）：把当前模块的主结果、指标和口径画成一张 980px 宽的 PNG，手机直接发微信/群里，不用截图裁边。
- **对比图 PNG**（方案快照页）：勾选 2–3 个方案后导出，图上带 A/B 方案名与备注。
- **导出底稿**：当前模块的输入 + 结果 + 口径写成 Markdown；**下载 CSV** 给表格软件。
- **打印 / 存 PDF**：工具栏「打印」打印当前模块；体检报告页还有「导出这份报告（PDF / 打印）」，在浏览器打印面板里选「另存为 PDF」即可。
- **分享链接**：地址栏带参数（`#模块?参数=值`），打开即回填并自动算；**方案快照**最多 20 条，支持排序（最新/最早/按模块/按方案名）与关键词筛选，另有整站备份/恢复。

### 支出结构与逐月记账的两个小功能

- 「家庭支出结构」表里，**偏离参考区间 5 个百分点以上的行标红**（浅橙＝小幅偏高、浅蓝＝小幅偏低），并在结果区直接列出「最该先改的项」。
- 「12 个月小结」的 72 格支持**一键摊平**：按上面 6 类的金额占比，把每个月支出摊到 6 个分类，每行合计正好等于该月支出，再按实际改几格即可。

### 模块之间「带参跳转」

结论里出现的链接会把**当前算出来的数**一起带过去，点一下就到目标模块并填好，不用重敲：
- 一页体检报告 → 应急金（月必需支出）、FIRE（支出/已有资产/年龄）、买房预算（收入）、保额（年收入/年支出/资产/负债）、年度报告（年收入/年支出）
- 家庭财务体检 → 一页体检报告（11 项一次搬完）、应急金
- 家庭支出结构 → 应急金、租还是买（房租）、保额、买车还是打车、一页体检
- 12 个月小结 → 支出结构（6 类全年金额自动折成月均）

实现就是在面板底部渲染 `<a href="#模块?字段=值&…">`，深链解析沿用「分享链接」那套（`hashTarget` + `applyParams`），所以直接粘到地址栏也同样成立。

### 财务工作流怎么串起来

5 条固定路径（出纳·报销记账 / 总账·结账报表 / 税务·申报 / 预算·分析）按岗位显示，点步骤直接跳到对应模块，并把**上一步算出来的结果**带过去（例如报表体检的收入成本 → 比率分析、增值税台账的销项进项 → 勾稽核对）。路径定义收敛在 `src/app.js` 的 `WF_PATHS`，每步只写「模块 + carry 列表」，加一步改一行即可。

几个细节：
- **打勾三态**：未做 → 本月完成 → 跳过，键是 `路径id:模块id`，不是 DOM 序号，中间插步骤也不会错位；老数据首次打开自动迁移。
- **月度归档**：「清空本月」会先把 `本月完成/总数` 存进归档（留 12 个月），再清空本月勾选，所以历史完成度查得到；归档里连当月的备注和预计时长一起存，换月时自动执行——上个月已经过去的截止日期会清掉，预计分钟留着复用。
- **一键走完**：可设每步停留时长，也可以选「逐步确认」——切到别的模块后底部会留一条浮动步骤条，随时「继续 / 跳过 / 结束」，走完给出结果汇总。
- **交接单**：.md / CSV / 复制三种，含每步状态、备注、预计时长、截止日期，以及「打开就是这一步的参数」的链接，直接发给接手的人。
- **自定义路径**可以搜索模块、排序、改名，还能生成 `#workflow?wfimport=…` 深链分享给别人一键导入。
- **内置路径也能改**：点「编辑步骤」后每条路径都摊开，每步右侧出现 ↑ ↓ ×——不适用的步骤（比如你们不做预算）可以藏掉，顺序也能调，点「恢复默认」一键还原。隐藏步骤的勾选/备注不会丢，恢复后还在。
- **步骤子清单**：每步的「☑」可以把这一步拆成几个小动作（收集发票、核对成本口径…），做完一个勾一个，路径上直接显示 `☑ 1/2` 和第一条没做完的，不用自己记。
- **上一步没算过会提醒**：某一步要用上一步的结果，但上一步没算（参数没动过）时，这一步的链接会标一个虚线下划线 + `!`，点进去底部弹出提示条「先去算 月度利润表 ▸」——避免拿默认值当真实结果。
- **首页「今天做什么」**：顶部一行提示下一次该做哪一步（优先取截止最近的），带预计时长、还剩几天截止、本月进度；点 × 当天不再显示。没用过工作流的人不会看到。
- **到期提醒**：给步骤设了截止日期后，可以开「到期提醒」——到期前 1 天和当天各推一条本地通知（走 Service Worker，装了主屏更稳），点通知直接回到工作流。权限被拒时会提示去站点设置里放开。
- **本月明细**：按「跳过 / 没做 / 已完成」分组列出全部步骤，跳过的连备注一起显示，月底能看清为什么没做。
- **打印交接单**：一键出打印版（表格 + 签字栏），在打印面板里选「另存为 PDF」就是可直接签字的交接单。
- 工作流数据（勾选、跳过、备注、自定义路径、岗位、归档）都进了「整站备份」，换机器恢复不丢。

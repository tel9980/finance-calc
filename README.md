# 财务计算器 · finance-calc

一个纯前端的财务计算器，托管在 Cloudflare Workers（Static Assets）。

线上地址：**https://js.1211.cc.cd**

## 功能

| 模块 | 算什么 |
| --- | --- |
| 存款利息 | 单利 / 按年复利 / 按月复利；利息、本息合计、实际年化、每月每天折合 |
| 贷款月供 | 等额本息、等额本金；月供、总利息、利息占本金比，逐期还款计划表 |
| 提前还款 | 缩期限保月供 / 减月供保期限两种方案；省息、期数变化、扣违约金后净省 |
| 复利/定投 | 初始本金 + 每月定投 + 年化收益；期末总额、累计收益、翻倍年数 |
| 年化换算 | 复利年化（CAGR）、单利年化、区间收益率、日均收益 |
| 通胀购买力 | 未来购买力折现、维持同等生活所需金额、购买力缩水幅度 |
| 个税测算 | 年度综合所得税额；年终奖「单独计税」与「并入综合所得」对比取优 |

## 特点

- 零依赖、零后端：3 个静态文件（`index.html` / `style.css` / `app.js`），约 30 KB。
- 全部计算在浏览器本地完成，不联网、不上传任何输入；填过的值只存在本机 `localStorage`。
- 移动端单列自适应，7 个模块用标签页切换，切换状态写进 URL hash（可直接分享 `/#loan` 这类链接）。
- CSP 白名单极严（`default-src 'self'`），因此页面内没有内联脚本与内联样式，改代码时请保持外部文件引用。

## 本地预览

```bash
cd public && python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

## 部署

```bash
export CLOUDFLARE_API_TOKEN=...      # 需要 Workers 脚本 + DNS 编辑权限
export CLOUDFLARE_ACCOUNT_ID=...
npx wrangler deploy
```

自定义域名在 `wrangler.toml` 的 `[[routes]]` 里配置，部署时 Cloudflare 会自动建 DNS 记录并签发证书。
换域名只要改 `pattern` 再 deploy 一次。

## 口径与免责

- 结果均为数学测算，未计手续费、税费、通胀等额外因素（通胀有单独模块）。
- 个税按现行综合所得与全年一次性奖金政策估算（全年汇算口径），实际以扣缴义务人申报与税务机关口径为准。
- 存款保险最高偿付 50 万元（本息合计，同一家银行）；理财不等于存款。
- 本项目不构成投资、信贷或税务建议。
